ÉTAPE 1 – à la racine du site
Sur GitHub, page principale de swoof-app.github.io :
Add file → Upload files → glisse index.html, sw.js et manifest.json
(du dossier « 1-a-mettre-a-la-racine ») → bouton vert « Commit changes ».

ÉTAPE 2 – dans le dossier img
Sur GitHub, clique sur le dossier « img » pour entrer dedans.
Add file → Upload files.
Ouvre le dossier « 2-a-mettre-dans-le-dossier-img » sur ton Mac,
sélectionne TOUTES les images (Cmd + A) et glisse-les (les fichiers, pas le dossier).
Attends que tout soit chargé → bouton vert « Commit changes ».
